# General-purpose variance preset

Use only the user's uploaded column metadata, the current FluxSpec, and the
request payload. Ask for the measure, period, scenario, grouping, and sign
convention when they are ambiguous. Prefer an additive sum measure for
reconciling movements. Do not assume positive values are favorable or infer
business cause from an account description. Keep the primary analysis generic;
add controls and review questions rather than making unsupported assumptions.
